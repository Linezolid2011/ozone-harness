设置
dream 把会话记录整理成背景档案：data/vault/README.md ＋ sections/ 段落 ＋ entities/ 实体。 它不改写记忆条目（那是你明确要求记住的那一套）。 「整理一次」会真正写档案并推进游标，而且不可撤销： 整理是单向门，不留快照、没有回滚。 预演已经取消了（它要真跑一遍模型、照样花钱，给出的却只是"会改什么"的估计）。 如果某一轮改坏了，补救的办法是下面「危险区」里的 格式化并初始化 dream：清空之后重新整理一遍就能再做出来， 代价是再花一次整理的钱 —— 但手写的内容不会回来。
档案可以直接在这里新建 / 编辑 / 删除： 左树顶上有「新建档案」，右边每一份的右上角有「编辑 / 删除」。 保存时界面会带上"你看着的那一版"的指纹；如果模型在你编辑期间改过它， 后端会拒一次并把最新内容摆出来，由你决定放弃还是覆盖。 删除 README 会被后端拒绝（它是索引），所以 README 上没有删除按钮。
手改不会自动更新 README 索引与别处的双链 —— 结构校验会提示"没有被 README 提到"之类的问题。 另外，整理正在运行时不能改档案（后端会直接拒绝），等它跑完再试。
